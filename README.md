# SANRIO SCHOOL FES 2026 — イベント紹介ウェブサイト

サンリオ×日本テレビ×NTTドコモ×ドコモ・スタジオ&ライブの4社共同企画として検討中の
「サンリオ学園祭フェス」のお客さま向けイベント紹介ページ(モック)です。
開催地案ごとに2バージョンを用意しています。

## コンセプト

- 街全体を「学園祭」の会場に(街なかエリアは入場無料)
- フィナーレはアーティスト×キャラクターの「放課後/後夜祭ナイトライブ」
- メインターゲット:中高生(学生証提示のスペシャルプライスを用意)

## 構成

- `index.html` — **渋谷・代々木公園バージョン(WINTER)**
  - 冬に始まる代々木公園の大規模イルミネーションとコラボ
  - 2026年12月19日(土)・20日(日)/放課後ナイトライブは代々木公園特設ステージ
- `yokohama.html` — **パシフィコ横浜・みなとみらいバージョン(AUTUMN)**
  - 「サンリオFes 2026」と同じパシフィコ横浜の設備・会場をそのまま活用する想定
  - 2026年11月21日(土)・22日(日)/後夜祭ナイトライブは国立大ホール(全席指定・屋内)
  - みなとみらいの街なか(観覧車ライトアップ・スタンプラリー)と連携

各ページはHTML/CSS/JSすべて同梱の1ページ完結構成で、ヘッダーのボタンから相互に行き来できます。
ブラウザで開くだけで閲覧できます(レスポンシブ対応)。
